# HardlyListening — design context

## Audience and use
A small private group (one admin, a handful of approved members) who share one
self-hosted music library. Mostly phones in a car or on headphones, some desktop
while digging through the Repository. The job: find a song or set, play it, save
it, take it offline.

## Personality
Quiet, utilitarian, warm-dark. A record shelf, not a dashboard. Confidence comes
from spacing, alignment and one green accent (`#58d3a8`), never from gradients,
glows or badges. Secondary text is dim, controls are ghost icons, and one thing
per screen is allowed to be bold.

## Not this
Neon-on-black, purple gradients, gamified counters, decorative hearts/stars on
tiles, glass cards, hover lifts that move content. Loud treatment reads as a
different product.

## Constraints
- No build step; `web/` is served as-is.
- Dark only; palette lives in `web/index.html` (`--bg --panel --panel2 --line
  --text --dim --accent --accent2`).
- Every control, id and handler stays when a layout changes: functional parity
  before tidying.
- Edit the authoritative CSS block; never append an override.
